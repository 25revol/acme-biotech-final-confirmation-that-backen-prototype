## Implementation Guide

### `backend/app/main.py`
**Purpose:** FastAPI application entry point with WebSocket support

Configure CORS, include all API routers, setup Socket.IO server with JWT authentication, implement startup health checks, register audit middleware

### `backend/app/core/security.py`
**Purpose:** Authentication and security utilities

JWT token creation/validation, password hashing with bcrypt, TOTP MFA generation/verification using pyotp, OAuth2 dependency injection for protected routes

### `backend/app/services/health_service.py`
**Purpose:** System health monitoring with circuit breaker

Check database connectivity, Redis availability, Celery worker status. Implement circuit breaker pattern with automatic recovery. Return detailed component status with response times and error messages

### `backend/app/services/submission_service.py`
**Purpose:** Data submission processing with validation

Accept JSON payload, calculate SHA-256 hash, persist to database, trigger async validation worker, return immediate confirmation with submission_id and timestamp

### `backend/app/services/websocket_service.py`
**Purpose:** Real-time WebSocket communication

Authenticate WebSocket connections using JWT, broadcast health status updates, send submission status changes filtered by user permissions, handle connection lifecycle

### `backend/app/workers/validation_worker.py`
**Purpose:** Asynchronous data validation with Celery

Consume validation tasks from Redis queue, perform data integrity checks, update submission status, broadcast results via WebSocket, implement retry logic with exponential backoff

### `backend/app/middleware/audit_middleware.py`
**Purpose:** Automatic audit trail generation

Intercept all API requests, capture before/after states, generate cryptographic signatures, store audit records with user attribution and session binding

### `frontend/src/components/Dashboard/SystemStatus.tsx`
**Purpose:** Real-time system health dashboard

Display overall system status (green/yellow/red), show component grid with individual health status, implement WebSocket connection for real-time updates, handle connection errors gracefully

### `frontend/src/components/Submissions/SubmissionForm.tsx`
**Purpose:** Data submission interface with validation

File upload or JSON input form, client-side validation with React Hook Form, real-time progress indicator, display immediate confirmation or detailed error messages, handle file size limits

### `frontend/src/components/Auth/LoginForm.tsx`
**Purpose:** User authentication with MFA

Username/password form, TOTP verification input, QR code display for MFA setup, handle authentication flow with JWT storage, redirect based on user role

### `frontend/src/services/websocket.ts`
**Purpose:** WebSocket connection management

Establish authenticated WebSocket connection, handle reconnection logic, subscribe to health and submission events, parse and distribute messages to React components

### `docker-compose.yml`
**Purpose:** Multi-service container orchestration

Define services for FastAPI backend, React frontend, PostgreSQL, Redis, Celery worker, Traefik reverse proxy. Configure networks, volumes, and environment variables. Setup SSL certificates and health checks

### `database/init.sql`
**Purpose:** Database schema initialization

Create all tables with proper constraints, indexes for performance, audit triggers, temporal table setup, initial admin user with MFA disabled for first setup
